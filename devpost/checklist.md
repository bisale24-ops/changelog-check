# Build checklist

- [ ] **S1 history** — the range between two tags as commits, files, churn and issue numbers.
      Done when `git log` and the tool agree on the commit count for three public repositories.
- [ ] **S2 notes** — a release note cut into claims. Done when headings, code blocks and link
      definitions are excluded and every bullet becomes exactly one claim.
- [ ] **S3 match** — evidence-based matching. Done when a planted false claim is not supported
      and an honestly written note has no unsupported lines.
- [ ] **S4 report** — three blocks, colour, exit codes, `--html`.
- [ ] **S5 evals** — `cases.json` over public repositories, run in CI.
- [ ] **S6 packaging** — README, licence, three-minute video, submission text.

Build starts after IBM Bob, on 28 September. Deadline for Build With AI: Basics is 27 October,
so the schedule has three weeks of slack.
